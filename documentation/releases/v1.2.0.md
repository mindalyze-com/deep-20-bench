# Deep20Bench 1.2.0

Deep20Bench 1.2.0 adds three model results to benchmark edition 1.1, expands the static
publication, and fixes provider caching and artifact storage issues.

Changes since 1.1.1:

- Add GPT-6.1 Sol (high), Claude Sonnet 5.5 (high), and Muse Wonder (high), each with
  30 scored trials across ten subjects. Edition 1.1 now compares 19 models; the
  historical edition 1 leaderboard retains its 18 models.
- Muse Wonder solves 29 of 30 games, scores 19.6 questions, and ranks 13th of 19.
  Add its dated news entry and links to the full run and transcripts.
- Prerender every selected run, subject summary, and episode transcript. Include all
  canonical content pages in the sitemap and permit crawling and indexing on every
  public page, including transcripts and the 404 page.
- Fix Umami visitor identification and page-view tracking, and preserve the news
  archive on desktop, phones, and without JavaScript.
- Bound Oracle research prompt-cache keys to 64 characters while preserving role,
  prompt, subject, and search-mode separation. Shorter keys retain their existing form.
- Support repository-relative references through external run-storage symlinks while
  retaining integrity, path, and answer-reuse checks.
- Scope error-output duplicate detection to each component.
- Regenerate the complete GitHub Pages site, including edition-specific downloads
  and the maintained edition 1 v9 dataset and schema.

Benchmark edition 1.1 remains official. Benchmark edition 1.2 remains an inactive draft;
this software release does not activate it or change the game rules or scoring.

Validation: the publication build and byte-for-byte reproducibility check, Vue/TypeScript
checks, lint checks, and strict Python type checks passed. All 123 focused offline Python tests and 18 desktop/mobile browser
tests passed. All 1,581 prerendered routes, 1,570 sitemap URLs, referenced assets,
crawler access, and v9 compatibility files were checked locally.
