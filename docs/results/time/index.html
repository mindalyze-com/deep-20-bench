Model time

Model time across the run.

Each bar is the total time of all calls to the tested model, as reported by the provider. Shorter is faster. This is not the total benchmark runtime.

Model time

Model time is the total time of all calls to the tested model (the Guesser) in the run, as reported by the provider.

End-to-end time

End-to-end time is the clock time from start to finish of the benchmark run. It includes model calls, answer checks, and waiting. Work that runs in parallel counts once.

End-to-end time

End-to-end benchmark time.

Each bar is the clock time from start to finish of the run. It includes model calls, answer checks, web search, and waiting for provider rate limits, so it says more about the test setup than about the model. It is sorted, not ranked.
