How it is calculated

Distance from the lowest score and cost.

Both measures use a 0-to-1 scale and have equal weight. Lower is better.

Formula√(scaled question score² + scaled Guesser cost²)
Calculation detailsSteps and limitsView ↓Hide ↑
  1. Scale question score as (value − lowest) ÷ (highest − lowest) across the compared models.
  2. Scale Guesser cost per round with the same calculation.
  3. Measure straight-line distance from (0, 0). Lower is better.

A model with scaled question score 0.06 and scaled cost 0.08 has distance √(0.06² + 0.08²) = 0.10.

The question score includes the fixed score for failed rounds.

Adding or removing a model can change every scaled value and rank.
