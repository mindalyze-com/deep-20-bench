What is public

Included: IDs, model settings, B20 and question scores, outcomes, costs, timestamps, source commit, and eligibility reasons.

Excluded: prompts, raw responses, provider traces, credentials, headers, environment values, and private subject data.

The publisher reads completed run files. It makes no model calls and does not change source runs.
