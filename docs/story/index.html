Origin · prior work

A shared idea, built into a benchmark.

The idea for Deep20Bench was sparked during a holiday while Patrick Heusser and Markus Tuor were playing Twenty Questions with the kids. Inspired by the game, Patrick went on to design and build the benchmark from the ground up.

Origin ↓
01

Origin

The game needs world knowledge and a plan for the next question.

One person chooses a subject. The others ask yes-or-no questions. Each answer should narrow the options.

Deep20Bench gives that task to an LLM. It counts how many questions the model needs to identify the subject.

Scope

What Deep20Bench measures.

01

Model as questioner

The model chooses each question. This tests world knowledge and question planning.

02

Limited input

The Guesser sees a broad category, its prior actions, and YES, NO, or UNKNOWN. It does not see the subject or Oracle data.

Public records

Each score links to its run, subject, transcript, evidence, and usage data.
