Public data

Edition 1 data.

Deep20Bench publishes all the data behind its leaderboard, not only the averages: runs, rounds, transcripts, evidence, outcomes, cost, and timing.

Project-authored result data and documentation are licensed under CC BY 4.0 and may be reused with attribution. Evidence excerpts from third-party sources are not covered.

02 Explore the file

Find the main records.

These four paths cover rankings, runs, rounds, and transcripts.

leaderboard[]
Ranks, models, question scores, success, format errors, cost, and time.
official_runs[]
Each ranked run in full: settings, totals, subjects, and all models used.
subjects[].trials[]
Each round's outcome, counted questions, score, cost, duration, and format errors.
trials[].episode
The round transcript: questions, answers, evidence, usage, timing, and format errors.

Example query

Print each model's rank, name, and exact question score.

jq -r '.leaderboard[] | [.rank, .model.display_name, .question_score] | @tsv' deep20bench-v10.json

Contents

What is and is not published.

Included

IDs, model settings, scores, outcomes, costs, timestamps, the source code commit, format errors, transcripts, Oracle evidence, and the source of each reused answer. Format error records can include the Guesser's invalid reply text.

Excluded

The answer-checking models' instructions, raw responses, and internal decisions; hidden reasoning; full provider messages; credentials; and private subject data. Private diagnostic files are not published.

The site is built from finished, signed run files. Building it makes no model calls and does not change the run files.
