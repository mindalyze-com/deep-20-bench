How well can AI models play Twenty Questions?

Deep20Bench is a public AI benchmark for large language models (LLMs). It measures how many questions a model needs to identify a hidden subject: a person, character, or thing. Most questions get a clear Yes or No. When the facts are unclear, the answer is Unknown.

How scoring works

The model only knows a broad category, such as “video game character”. It gets up to 50 questions, more than the traditional twenty, so more rounds can finish. Each question, wrong guess, or reply in the wrong format adds one to the score. If the model never finds the subject, the round scores 51. The final score is the average over all rounds; lower is better.

This edition

This edition compares 18 models on seven subjects, with five rounds per subject. All results and transcripts are public. Each edition has its own comparison settings and results.

What the game tests

The game combines several abilities.

Each answer should improve the model’s next question. Why this game works →

01

World knowledge

Know which facts help narrow down the subject.

02

Question strategy

Choose questions that remove many possibilities.

03

Using earlier answers

Use all earlier questions and answers to plan the next question.

04

Knowing when to guess

Guess at the right moment, before the limit.

How the game is played

The Guesser asks. Other models answer and check.

The Guesser is the model being tested: it asks yes-or-no questions and makes the final guess. For every question, the Oracle searches the web and cites evidence instead of relying on memory. A Reviewer checks every YES or NO against that evidence without seeing the Oracle's answer. If they disagree, a Judge decides without seeing either answer. The Guesser receives only the final YES, NO, or UNKNOWN.

How this is scored

Round scores are averaged for each subject, then across subjects. A failed round gets the fixed failure score.

The 95% confidence interval shows how certain the average is, based on repeated rounds on these subjects. A wider interval means less consistent results. It does not predict scores on other subjects.

How to read the results

Same test setup, limited conclusions.

We test a small, fixed set of subjects. Every game record is public, so you can check the results. What the results can show →

01

Consistent setup

Models in each edition use the same subjects, number of rounds, question limit, and scoring rules.

02

Failures stay visible

A failed round gets a fixed score. Before the question limit, a reply in the wrong format uses up a turn.

03

Public records

Each model's results link to every subject, round, question, answer, source, cost, and time.

Origin

From a holiday game to a benchmark.

Patrick Heusser and Markus Tuor came up with the idea while playing Twenty Questions with the kids. Patrick then designed and built the project.
