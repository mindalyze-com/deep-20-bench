Deep20Bench 1.1 · Current edition

How well can AI models play Twenty Questions?

Deep20Bench is a public AI benchmark for large language models (LLMs). It measures how many questions a model needs to identify a hidden subject: a person, character, or thing. Most questions get a clear Yes or No. When the facts are less clear, the answer can be Rather yes, Rather no, or Unknown.

How scoring works

The model only knows a broad category, such as “video game character”. It gets up to 40 questions, more than the traditional twenty, so more rounds can finish. Each question, wrong guess, or reply in the wrong format adds one to the score. If the model never finds the subject, the round scores 41. The final score is the average over all rounds; lower is better.

This edition

This edition compares 20 models on 10 subjects, with 3 rounds per subject. All results and transcripts are public. Each edition has its own comparison settings and results.

What the game tests

The game combines several abilities.

Each answer should improve the model’s next question. Why this game works →

01

World knowledge

Know which facts help narrow down the subject.

02

Question strategy

Choose questions that remove many possibilities.

03

Using earlier answers

Use all earlier questions and answers to plan the next question.

04

Knowing when to guess

Guess at the right moment, before the limit.

How the game is played

The Guesser asks. Other models answer and check.

The Guesser is the model being tested: it asks questions and makes the final guess. The Oracle answers using web research and, if the run's rules allow, its own knowledge. A Reviewer checks every answer except Unknown without seeing the Oracle's answer. If they disagree, a Judge decides without seeing either answer. The Guesser receives only the final answer.

How to read the results

Same test setup, limited conclusions.

We test a small, fixed set of subjects. Every game record is public, so you can check the results. What the results can show →

01

Consistent setup

Models in each edition use the same subjects, number of rounds, question limit, and scoring rules.

02

Failures stay visible

A failed round gets a fixed score. Before the question limit, a reply in the wrong format uses up a turn.

03

Public records

Each model's results link to every subject, round, question, answer, source, cost, and time.

Origin

From a holiday game to a benchmark.

Patrick Heusser and Markus Tuor came up with the idea while playing Twenty Questions with the kids. Patrick then designed and built the project.
